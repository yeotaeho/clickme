## 1. 프로젝트 개요

| 항목 | 내용 |
|------|------|
| **서비스명** | Persona.100 (가칭) |
| **카테고리** | B2B SaaS / 마케팅 테크 (MarTech) |
| **핵심 가치** | 실제 예산 집행 *전*, 100개 AI 페르소나로 마케팅 성과를 사전 시뮬레이션 |
| **타깃 고객** | 마케팅 대행사, 인하우스 마케터, 스타트업 PMM, 대기업 브랜드팀 |

**한 문장 요약**

> "실제 돈을 쓰기 전에, 100명의 가상 타깃 고객에게 먼저 물어보세요."

Persona.100은 100개의 초개인화된 AI 에이전트를 활용해 광고 소재(이미지·영상)의 성과를 사전 예측하고, 타깃 고객의 니즈를 가상으로 리서치하는 플랫폼입니다.  
실제 매체비를 쓰기 전에 타깃 오디언스와 동일한 페르소나를 가진 AI 그룹에게 **가상 FGI(포커스 그룹 인터뷰)** 와 **A/B 테스트**를 진행하여 마케팅 실패 확률을 제로에 가깝게 줄여줍니다.

## 2. 배경 및 시장 문제

현재 퍼포먼스 마케팅·브랜드 캠페인 시장에는 다음 세 가지 구조적 비효율이 존재합니다.

### 2-1. 비용을 태우며 정답을 찾는 구조
- A/B 테스트를 위해 메타·구글 등 실제 매체에 라이브를 진행해야만 데이터를 확보할 수 있음
- 필연적으로 **"실패한 시안에 소진되는 매몰 비용"** 발생

### 2-2. 물리적 한계에 부딪힌 고객 리서치
- 타깃 고객의 진짜 속마음을 파악하는 FGI·대규모 설문조사는 **수천만 원 / 수 주 소요**
- 중소규모 캠페인에서는 엄두조차 내지 못하는 현실

### 2-3. 데이터 없는 감각 의존적 의사결정
- 사전 데이터 부재 → 최종 광고 시안을 결정할 때 실무자의 직감 또는 내부 의사결정권자의 개인 취향(**HiPPO 현상**)에 의존
- 팀 내 의견 충돌, 클라이언트와의 마찰로 이어짐

## 3. 기획 의도 & 솔루션

### 패러다임 전환

```
기존: 사후 분석 (Post-mortem)  →  신규: 사전 검증 (Pre-simulation)
```

### 솔루션 요약

사람과 구별할 수 없는 수준의 정교한 페르소나를 부여받은 **100개의 LLM 에이전트 그룹**을 생성합니다.

| 캠페인 단계 | 사용 기능 | 결과물 |
|------------|----------|--------|
| 제품 기획 단계 | 가상 설문조사 (Synthetic Survey) | 타깃 페인포인트 · USP 발굴 |
| 광고 배포 직전 | 광고 시안 평가 (Ad Simulator) | 예상 CTR, 전환 의향 점수, 연령대별 호감도 |

단 **5~10분** 만에 비용 소진 없이 정량·정성 결괏값을 획득합니다.

## 4. 핵심 기능

### 4-1. 초개인화 가상 타깃 설문조사 (Synthetic Survey)

- **페르소나 구성**: 나이, 직업, 소득수준, 관심사 등 세밀한 지표를 슬라이더로 조절해 100명의 타깃 풀 생성
- **질문 유형**: 주관식 / 객관식 자유 설정
- **활용 예시**:
  > "여름용 쿨링 셔츠를 살 때 가장 고민되는 점은?"  
  → 타깃의 결핍과 페인포인트를 사전 파악 → 광고 카피 핵심 소구점(USP) 발굴

### 4-2. 멀티모달 광고 성과 시뮬레이터 (Ad Performance Simulator)

- **입력**: 배너 이미지 또는 짧은 영상 업로드
- **평가 요소**: 디자인, 카피 가독성, 매력도 종합 평가 (Vision API 기반)
- **출력 데이터**:
  - 예상 클릭 확률 (%)
  - 구매 전환 의향 점수 (1~100점)
  - 타깃 연령층별 호감도 편차

### 4-3. 실시간 다차원 분석 대시보드 (Analytics Dashboard)

- **시각화**: 시각화 차트 + 인스타그램 댓글창 형태의 피드백 UI
- **AI 액션 아이템 자동 도출** 예시:
  > "30대 여성 그룹의 클릭률이 낮습니다. 배경을 더 밝은 톤으로 수정하고 카피의 위치를 중앙으로 배치해 보세요."
- **기술**: SSE(Server-Sent Events)로 에이전트 반응 실시간 스트리밍

## 7. 기술 아키텍처

### 7-1. 시스템 구성 요약

```
[Frontend: Next.js + TypeScript]
        ↕  SSE (실시간 스트리밍)
[Backend: FastAPI (Python, 비동기)]
        ↕
[LangGraph 오케스트레이션]
  ├── Agent 1 ~ Agent 100 (독립 워크플로우)
  ├── 프롬프트 엔지니어링 (할루시네이션·동질화 방지)
  └── Vision API (멀티모달 이미지/영상 분석)
        ↕
[pgvector (Vector DB)]
  └── 페르소나 컨텍스트 임베딩 (RAG 방식 주입)
```

### 7-2. 기술 스택 상세

| 레이어 | 기술 | 역할 |
|--------|------|------|
| **Frontend** | Next.js (TypeScript) | UI 렌더링, SSE 실시간 대시보드 |
| **Backend** | Python FastAPI | 비동기 API 서버, LLM API 병목 방지 |
| **AI 오케스트레이션** | LangGraph | 100개 에이전트 독립 워크플로우 제어 |
| **벡터 DB** | pgvector (PostgreSQL) | 페르소나 임베딩 저장 + RAG 조회 |
| **멀티모달** | Vision API | 이미지·배너 인식 및 평가 |
| **실시간 통신** | SSE (Server-Sent Events) | 에이전트 반응 스트리밍 |

### 7-3. 핵심 설계 원칙

1. **할루시네이션 방지**: 에이전트별 독립 프롬프트 + 출력 검증 체인 적용
2. **동질화(Echo Chamber) 방지**: 페르소나 간 다양성 확보를 위한 Temperature·시드 분산 전략
3. **확장성**: 에이전트 수를 100개 이상으로 스케일 아웃 가능한 비동기 구조
4. **응답 속도**: FastAPI 비동기 처리로 대규모 LLM API 동시 호출 최적화

## 8. 개발 우선순위 & 로드맵

> 마케팅 도메인 지식이 필요한 **'광고 자동 제작'은 제외**하고,  
> 가장 빠르게 가치를 입증할 수 있는 **'가상 설문조사 & 평가 시뮬레이터'에 집중**합니다.

### Phase 1 — MVP (핵심 검증) 
**목표**: 설문조사 + 시뮬레이터 기본 동작 검증

- [ ] 페르소나 생성 UI (슬라이더 기반)
- [ ] LangGraph 기반 100 에이전트 오케스트레이션 기반 구축
- [ ] 가상 설문조사 (Synthetic Survey) 기능 구현
- [ ] 기본 결과 대시보드 (텍스트 응답 집계)

### Phase 2 — Core Product
**목표**: 멀티모달 분석 + 실시간 스트리밍

- [ ] 멀티모달 광고 시뮬레이터 (이미지 업로드 + Vision API 연동)
- [ ] SSE 실시간 스트리밍 대시보드
- [ ] pgvector 기반 페르소나 RAG 파이프라인
- [ ] AI 액션 아이템 자동 도출 기능

### Phase 3 — Growth & Monetization
**목표**: B2B 판매 가능한 완성형

- [ ] 티어별 구독 플랜 (Starter / Professional / Enterprise)
- [ ] 분석 리포트 PDF 다운로드
- [ ] 영상 소재 시뮬레이션 지원
- [ ] Enterprise 커스텀 페르소나 + API 연동
